## Project Title
AI StudyBuddy

## Description
AI StudyBuddy is a student learning assistant that helps learners organize study tasks,
track progress, practice with quizzes, maintain notes, and receive study guidance.

## Technology Stack
- Python
- Flask
- HTML5
- CSS3
- JavaScript
- LocalStorage

## Run the project
1. Install Python.
2. Open a terminal in this project folder.
3. Run:
   `pip install -r requirements.txt`
4. Run:
   `python app.py`
5. Open the URL shown in the terminal, normally:
   `http://127.0.0.1:5000`

## Demo
The app also contains a browser-based frontend. The AI assistant uses local demo responses;
a real AI API/backend can be connected later if required.
