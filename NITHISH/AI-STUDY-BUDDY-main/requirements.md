# Phase 2 — Requirement Analysis

## Functional Requirements
1. Display student study progress.
2. Add and complete study tasks.
3. Conduct a short quiz and calculate score.
4. Create and save study notes.
5. Provide study guidance through an assistant.
6. Display team and project information.

## Non-Functional Requirements
- Responsive UI
- Easy navigation
- Simple interface
- Fast browser interaction
- Local note persistence

## Hardware/Software
- Modern laptop/desktop or mobile browser
- Python 3.x for Flask mode
- Chrome/Edge/Firefox
